# Посмотри в окно
https://github.com/Errwith/posmotri-v-okno-ad)

Проектная работа курса «Фронтенд-разработчик» Яндекс Практикума.

Приложение показывает видео из окон разных городов. Поиск работает по городу
и времени суток: можно отметить утро, день или ночь и получить подходящие
ролики. Клик по карточке меняет видео в большом блоке, кнопка «Показать ещё»
подгружает следующую порцию карточек.

## Стек

- HTML
- CSS (flexbox, кастомные элементы форм, состояния `:hover`, `:active`,
  `:focus-visible`)
- JavaScript (логика загрузки данных и шаблоны `<template>`)

## Запуск

Откройте `index.html` в браузере или запустите локальный сервер из папки
проекта, например:

```bash
npx http-server
```

## Структура проекта

- `index.html` — разметка страницы и шаблоны карточек;
- `styles/style.css` — стили страницы;
- `styles/preloader.css` — стили прелоадера;
- `styles/error.css` — стили блока с ошибкой;
- `fonts/fonts.css` — подключение шрифтов;
- `scripts/script.js` — логика приложения.
